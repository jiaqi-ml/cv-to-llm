# cv-to-llm

从计算机视觉走向大模型与多模态的学习记录。

目标是 2027 年春季进入大模型 / Agent / 多模态方向的实习，这个仓库用来存放每周的练习代码、调试记录和周报。

## 目录

- [`week01/`](./week01/) — Python 基础：计数、筛选、关键词统计、倒排索引

## 环境

- macOS (Apple Silicon)，Python 3.13
- 计划从 W3 开始使用 PyTorch（MPS 后端）

## 每周结构

每个 `weekNN/` 目录包含：

- `README.md` — 本周目标与逐日安排
- `exercises/` — 短练习，每题一个文件
- `debug_log.md` — 实际遇到并修好的问题（现象 → 假设 → 定位 → 修复）
- `weekly_report.md` — 本周实际投入与验收结果
