## 2. 今天会了什么

1. **累加变量**：`total = 0` 放在循环**外**，循环体内 `total = total + n`。放里面会被每轮清空。
2. **擂主法求最大值**：先让 `champion = nums[0]` 当擂主，循环里逐一挑战，`n > champion` 就换人。**不能设成 `0`** —— 输入全是负数时会得到 `0`，而 `0` 根本不在列表里。
3. **筛选要用结果列表**：`result = []` 同样必须在 `for` 外初始化，循环里 `result.append(n)`。
4. **边界判断的位置**：`if len(nums) == 0` 必须写在 `nums[0]` 取值**和**除法**之前**，否则分别报 `IndexError` 和 `ZeroDivisionError`。
5. **`/` 与 `//` 的区别**：平均值必须用 `/`，用 `//` 会把 `1.5` 截成 `1`。

## 3. 今天遇到的错误

### 错误 1：函数只写了"防崩溃"，忘了写"主逻辑"（`ex02_max.py`）

- **现象**：底部 `check()` 函数对非空列表一律返回 `None`。
  ```
  check([3, 9, 2, 7])   -> None    （期望 9）
  check([-5, -1, -9])   -> None    （期望 -1）
  check([])             -> None    ✅
  ```
- **原因**：把"防崩溃的边界判断"当成了"功能的全部"。文件上半部分三段 print 版有完整的擂主循环，但抽成函数时只搬了 `if len(nums) == 0`，没搬 `for` 循环和 `return`。
- **暴露方式**：把函数单独抽出来，用三组输入各跑一次 —— 只有 `[]` 那组是对的，问题立刻现形。
- **教训**：**边界判断只保证"不崩"，不保证"算对"。** 写完函数要列一张输入表，每组都跑，不能只测一个。

### 错误 2：`pass` 是 Python 关键字，函数名只能写成 `passs`

`ex04_pass.py` 里 `def passs(nums):` —— 能跑，但 `passs` 拼写无意义。更好的名字是 `count_pass` / `count_passed`，一眼看出是"计数"。

同理 `check` / `even` 这类名字太泛，看不出"在算什么"。练习册自检里就有这条：**变量名能让人看懂意图吗？**

### 错误 3：文件名少了一个字母

存成了 `ex03_eve.py`，实际应为 `ex03_even.py`（少了个 `n`）。文件名和后缀一样，错了不会报错，只会在以后找不到。

### 错误 4：复制粘贴导致注释与代码不一致

`ex02_max.py` 里两处：

| 位置 | 注释写着 | 实际是 |
|---|---|---|
| 第 22 行 | `让 n 依次变成 4、1、9、6` | 列表是 `[3, 9, 2, 7]` |
| 第 29、43 行 | `应该是 9` | 其中一组实际得 `-1` |

复制上一段代码时忘了改注释。**注释和代码不一致，比没有注释更糟** —— 以后回看会被误导。

### 错误 5：多余的边界判断

`ex03_even.py` 里的 `if len(nums) == 0: return []` 是**多余**的。空列表进 `for` 什么都不做，`even_nums` 本来就是 `[]`。

但 `ex_average.py` 里同样的判断**必须留着** —— 因为要除以 `len(nums)`，空列表会 `ZeroDivisionError`。

**判断该不该留：看空输入会不会让后面的代码崩。** 能少写一个分支就少写一个。
