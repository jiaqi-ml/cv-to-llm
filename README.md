# cv-to-llm

从计算机视觉走向大模型与多模态的学习记录。

目标是 2027 年春季进入大模型 / Agent / 多模态方向的实习，这个仓库存放每周的练习代码、调试记录与周报。

## 环境

- macOS (Apple Silicon)，Python 3.13
- 计划从 W4 开始使用 PyTorch（MPS 后端）

## 每周结构

每个 `weekNN/` 目录包含：

| 文件 | 作用 |
|---|---|
| `README.md` | 本周目标、逐日安排、验收标准 |
| `详细学习计划.md` | 逐日任务的权威版本（与 README 冲突时以此为准） |
| `diagnosis.md` | 起点诊断，闭卷作答记录 |
| `debug_log.md` | 实际遇到并修好的问题（现象 → 假设 → 定位 → 修复） |
| `weekly_report.md` | 本周实际投入与验收结果 |
| `exercises/` | 短练习，每题一个文件 |
